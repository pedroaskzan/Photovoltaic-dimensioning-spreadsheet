# Photovoltaic-dimensioning-spreadsheet
[2026] [WIP] (PV; Excel; PVSyst; Tariffs; Payback; Brazil) Concluding Curso Solar by Prof. Dr. Elmer Cari, from USP, we learned a lot on photovoltaic systems. With this project i use a photovoltaic system payback spreadsheet as base, and make my own based in what i've learned in the course and my Excel skills. I expand to other systems, not only Group B.
## Procedure
Learned from Curso Solar by Doctor Professor Elmer Pablo Tito Cari from EESC USP, and used my Excel skills and knowledge on Brazil's tariffs and charges way to expand the provided spreadsheet, bringing it from only Group B to Group A users using green and blue tariffs.
